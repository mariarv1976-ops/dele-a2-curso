# Curso y simulacros DELE A2 · 2spanishteachers.com (privado)

Copia de trabajo de todo el material del proyecto de claude.ai «DELE A2 Simulacros Examenes».

- El **proyecto** de claude.ai guarda solo lo esencial: las instrucciones, el estado corto, las referencias y el índice.
- Este **repositorio** guarda todo lo demás, con las mismas rutas que tenía en el proyecto (`claude/...` y la raíz).

## Cómo se usa en cada chat

1. **Al empezar**: clonar este repositorio y leer `claude/DELE_A2_instrucciones_proyecto.txt` y `claude/DELE_A2_curso_estado.txt`. Después, abrir solo los archivos de la pieza que toca; `indice_archivos.md` dice qué es cada uno.
2. **Para ejecutar**: los builds se ejecutan desde la carpeta donde están, junto con `claude/curso_comun.py`. Por ejemplo, `cd claude && python3 build_R08_conectores.py`.
3. **Al terminar**: commit y push de los builds, bancos, fuentes y datos nuevos o cambiados. Después, actualizar el estado corto (aquí y en el proyecto) y añadir lo hecho a `historial/`.

## Carpetas

- `claude/` y la raíz: programas, bancos, fuentes, datos y documentos de referencia, tal como estaban en el proyecto.
- `historial/`: el estado largo completo, del 11/10 al 23/10/2026, con todos los detalles técnicos de cada pieza.
- `indice_archivos.md`: qué es cada archivo.

Los PDF y la imagen originales no están aquí: los tiene María. Lo útil está resumido en `claude/DELE_A2_referencias_oficiales.md`.
